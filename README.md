# Nexor — Site institucional

Site estático (HTML, CSS e JavaScript puro), sem dependências nem etapa de build.

## Estrutura

- `index.html` — página inicial
- `portfolio.html` — portfólio completo
- `styles.css` — estilos
- `script.js` — interações
- `portfolio-dados.js` — lista dos trabalhos do portfólio
- `assets/` — logos e arquivos do portfólio (veja `assets/portfolio/LEIA-ME.txt`)

## Como ver localmente

Abra o `index.html` no navegador, ou sirva a pasta com qualquer servidor estático.
